# COPY RULES. C2 enforces these with veto power over every string in the project.

Voice: a dry bank registry that knows its own worth, with very thin humour.
Active voice. Sentence case. Every element does exactly one job. If a sentence
has to be read twice, it is broken.

## Banned outright

Punctuation and shape
- em dashes, en dashes used as em dashes, and double hyphens. None anywhere, in
  any form, including code comments, alt text, tweets and file names.
- exclamation marks in the interface
- tracked out all caps eyebrow labels sitting above blocks
- meta strings joined with middle dots, the A dot B dot C pattern
- an arrow character appended to button or link text
- rhetorical questions as headings
- colons used to make a heading sound weighty

Constructions
- "not just X, but Y"
- "it's not about X, it's about Y"
- "worth noting", "it's important to note", "in today's world",
  "at the end of the day", "let's dive in", "here's the thing"
- three item lists used as rhythm rather than as information
- sentences that open with "Whether you..."

Vocabulary
delve, tapestry, testament, unlock, unleash, elevate, journey, robust, seamless,
leverage, harness, realm, landscape, navigate, embark, crucial, vital, pivotal,
game changer, revolutionize, empower, foster, holistic, meticulous, intricate,
comprehensive, curated, bespoke, dive deep, deep dive, ecosystem (as a
metaphor), transform, redefine, reimagine

## Required

- Any word the whitepaper uses for a thing, we use for that thing: banker,
  charter, branch, license, retire, resolution fee, dormant, epoch, net flow,
  expansion, contraction, the ghost.
- Bank register register diction where it fits: issued, recorded, entered,
  presented, examined, endorsed, stamped, void, on file.
- Numbers: only what is in 01-FACTS.md.
- The word "unofficial" appears above the fold and is never softened.

## Tone calibration, three examples

Wrong, marketing: "Unlock your official Standard Reserve charter today."
Wrong, try hard: "the office is closed. the paper is not."
Right: "Issued on request. Confers nothing."

Wrong: "Take our quiz to reveal your unique banker archetype."
Right: "The examination is optional. It changes the stamp, not the paper."

Wrong: "Oops, something went wrong."
Right: "Nothing entered. The clerk needs a name."
