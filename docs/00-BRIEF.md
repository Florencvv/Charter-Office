# CHIEF'S BRIEF — The Charter Office
Internal. Read this before you write a word. Distributed to every agent.

## What exists in the world

The Standard Reserve is a protocol. Whitepaper v0.1 is published at
standardreserve.xyz/whitepaper/. Nothing is live: the protocol site shows
"Coming Soon: The Genesis Mint" and a whitelist checker. No token, no NFT.

The official site's own look, for contrast only, never to copy: near black
sidebar, white content column, one large black card holding a grayscale
photographic render of ruined towers, a neo grotesque sans (KH Teka), tight
uppercase micro labels. Modern, cold, photographic.

## What we are building

"The Charter Office". An unofficial registry office run by @flxrnc. One line:
the protocol issues licenses, this office issues the paper.

Two windows. Window 1 issues a certificate instantly from any typed string.
Window 2 is an optional 7 question examination that stamps the certificate
already issued. The quiz never gates the paper.

## The single taste rule

One bold element on the whole site: the engraving. Everything else is quiet
enough to be furniture. If a decision makes the page louder, it is wrong.

Deliberate distance from the protocol site: they are photographic and cold, we
are printed and warm. They render towers, we cut lines. Nobody should mistake
one for the other, and nobody should think we are mocking them either.

## Palette direction from Chief, argue with it if you have something better

Not cream and terracotta. Real security printing used a tinted safety paper,
an intaglio ink that is brown black rather than pure black, and a second colour
for numbering, usually a red orange. Start there. Historical, and it dodges
every default.
